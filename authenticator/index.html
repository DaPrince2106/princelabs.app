🔐 About

Authenticator generates TOTP codes for two-factor authentication entirely on-device. No accounts, no cloud sync, no servers. All secrets stay in local storage. Zero network permissions required.

No analytics. No tracking. Works fully offline.

✨ Features

  • Generate TOTP 6-digit codes from standard secret keys
  • Save accounts with custom names for quick access
  • One-tap code copy with haptic feedback
  • Real-time countdown showing code expiry
  • All data stored locally — works fully offline
  • Zero network permissions, no analytics, no tracking

❓ FAQ

How do I add an account?
Tap the Authenticator tab, enter a name, paste the secret key from your 2FA provider, then tap Save. The 6-digit code appears immediately.
Where do I find my secret key?
When enabling 2FA on a service (Google, GitHub, Instagram, X, etc.), look for Setup key or Secret key — a long string of letters and numbers.
How do I copy a code?
Tap the 6-digit code. It copies to your clipboard and a checkmark confirms it.
Is my data safe?
Yes. Authenticator never connects to the internet. Your secrets stay on your device in local storage. No accounts, no cloud, no analytics. Zero network permissions.
Can I delete an account?
Yes. On the Accounts tab, tap the X icon next to any account. Confirm deletion when prompted.
